# M0 foundation report

## Works

A strict TypeScript project builds a Phaser training-ground placeholder. The shared simulation advances an integer 30 Hz clock in Node and in a browser Worker. The page connects to a local Colyseus room; the room rejects mismatched protocol or content versions at authentication. A small versioned normalized map format validates dimensions, terrain and wall bounds/IDs. CI installs the lockfile, validates content, tests and builds.

Run instructions are in the README. On November 4, 2026, `npm test`, `npm run validate:map`, and `npm run build` passed. A local browser displayed the Worker at tick 30 / 1 second and a connected version-matched server. These are foundation checks, not playtests.

## Decisions

- Phaser 3.90 and the Colyseus 0.16 family are pinned. Colyseus 0.18 requires Node 22; this initial environment runs Node 20. The 0.16 client and server APIs were checked against the [versioned official documentation](https://0-16-x.docs.colyseus.io/). Revisit the major upgrade before any public deployment.
- The normalized map is deliberately minimal and is not yet a Tiled importer or the complete production schema. Add authored layers, spawn/objective validation and reachability when those features are introduced.
- Client reference for future measurements: MacBook Pro (2021), Apple M1 Pro 10-core, 16 GB RAM, Chromium 140.0.7339.186 (Playwright build 1193). Candidate server reference: 2-vCPU/4-GB Linux VPS. No performance measurement or capacity claim has been made.

## Limitations and next steps

M0 foundation checks are **complete**: Playwright verifies the browser Worker round trip, a valid connection, and rejection of mismatched protocol and content versions. CI can run these checks when manually triggered for a substantial checkpoint. Routine verification runs locally. The map has no spawn or objective schema yet. There is no movement, combat, multiplayer game, offline support, or deployment configuration. Gate A has not been reached; no human playtest result is claimed.

The November 4 npm audit reported advisories in development tooling and the Colyseus 0.16 dependency tree, including critical and high findings. Review the applicable advisories and upgrade or mitigate them before exposing a server publicly. The sample HTTP endpoint, room and connection have not been hardened for production. The development server is intended only for local use. The generated Phaser bundle is currently larger than Vite's default chunk warning threshold.
