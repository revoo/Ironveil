# M2 cannon laboratory — in progress

The first combat slice adds minimum-charge tap shots, 1.5-second charging, charge-scaled damage/speed and movement cost, cancellation, reload, and automatic venting. The Worker owns charge time, projectiles, target HP and target reset. Left mouse holds/releases the cannon; right mouse cancels. Stationary orange targets have health bars and reset three seconds after destruction. The ring and HUD show charging; the barrel determines shot direction. Focus loss and stale input cancel charging. Fast press/release edges are queued separately from movement.

Run `npm run dev` and open http://127.0.0.1:5173/. Aim at an orange target, tap or hold/release the left mouse button, or cancel with right mouse. Movement controls remain WASD and Shift.

Local verification: 14 Vitest tests and four Playwright tests pass; production build passes. New tests cover same-tick tap, recovery boundaries, full damage, venting, muzzle obstruction, swept geometry, target survival/reset, and browser tap-to-hit through Worker authority. CI was not triggered for this intermediate slice.

Effective 30 Hz thresholds: charge 45 ticks, full-charge hold 45, reload 20 (0.667 s), cancel recovery 8 (0.267 s), vent recovery 24 (0.8 s). No balance values were changed; durations round up to whole ticks.

Remaining M2 work: moving targets and relative-motion collision, accumulated same-tick damage/trades, player HP/death/reset, comprehensive collision ordering tests, reset control, charge-scaled recoil/audio/impact feedback, and deliberate input deduplication. The current sandbox has stationary damage targets and does not represent a multiplayer combat implementation. It does not yet support the full Gate A evaluation.

Gate A: **not ready / awaiting completed prototype and human playtest**. No combat playtest result is claimed. Online work remains downstream of this gate.
